# Running the eval (Colab GPU) and finishing on the laptop

## A. Push the repo to GitHub

```bash
# from the project root (already a git repo with 2 commits)
gh repo create document_enterprise_platform --private --source=. --push
# or: create the repo in the GitHub UI, then
#   git remote add origin https://github.com/<you>/document_enterprise_platform.git
#   git push -u origin master
```

The 120 raw documents are **not** committed (regenerated by the notebook). `data/eval/manifest.jsonl` is committed.

## B. Colab run (~35 min on a T4)

1. Open <https://colab.research.google.com> → File → Upload notebook → `notebooks/colab_runner.ipynb`
   (or open it straight from GitHub).
2. **Runtime → Change runtime type → T4 GPU**.
3. First cell: set `REPO_URL` to your repo URL.
4. **Runtime → Run all.** The cells:
   - `colab_bootstrap.sh` — installs deps, Ollama (GPU) + `qwen2.5:3b-instruct-q4_K_M`, a Qdrant server
   - regenerates `data/` (SROIE + CUAD download, synthetic PDFs) if missing
   - `run_all_eval.sh` — pipeline over 120 docs → build index + snapshot → retrieval queries →
     `eval_extraction.py` → `eval_retrieval.py` → `artifacts_bundle.zip`
   - prints `artifacts/eval_report.md` and downloads `artifacts_bundle.zip`

If the GPU session drops, just Run all again — parsed docs are cached and the LLM pass restarts.

## C. Finish on the laptop

```bash
# unzip the bundle into ./artifacts  (gives pipeline_results.jsonl, metrics.json, parsed_cache/, ...)
unzip -o ~/Downloads/artifacts_bundle.zip -d .

# warm the parse cache so local indexing is fast, then re-embed into local Qdrant (~10 min CPU)
cp artifacts/parsed_cache/* data/cache/ 2>/dev/null
docker compose up -d postgres qdrant
python scripts/build_index.py --recreate

# regenerate metrics locally (instant) and load rows for the review queue
python scripts/eval_extraction.py
python scripts/eval_retrieval.py --k 5
python scripts/load_results_to_db.py

# demo
uvicorn dip.api.main:app --port 8000 &
streamlit run src/dip/ui/app.py          # http://localhost:8501
```

The **Metrics** tab now shows field accuracy / classification / manual-verification reduction /
Top-5 retrieval + the calibration plot. The **Review Queue** tab has the low-confidence docs;
edit one and Approve to see it re-index. **Upload** a fresh PDF to run the live local path
(slow — Qwen on CPU — but it proves "fully local").
